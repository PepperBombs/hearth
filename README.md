# Hearth

Hearth is a self-hosted home for small personal web apps ("mini-apps"): a
dashboard of widgets, a sidebar, a quick switcher, light and dark themes, and
an English and Chinese interface. Each mini-app is a self-contained folder
that uses only the Hearth SDK.

This repository holds the framework and the SDK. Mini-apps live in a separate
repository, and your own data lives outside both.

Status: early development. Nothing here is ready to use yet.
