# Hearth

Hearth is a self-hosted home for small personal web apps: a dashboard of
cards, a sidebar, a quick switcher, light and dark themes, and an English and
Chinese interface. Each person makes the apps they want by describing them in
a chat with their own model, or adds one that Hearth ships. An app is a page
that runs in the browser's sandbox, and its data stays on your server.

This repository holds all of Hearth. Your own data lives outside it.

Status: early development. Nothing here is ready to use yet.
